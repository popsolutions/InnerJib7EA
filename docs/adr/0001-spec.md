# ADR-001 — InnerJib7EA / POPC_16A locked specification

**Status:** Accepted (2026-05-05)

## Context

InnerJib7EA is the first Sail of the PopSolutions fleet — explicitly chosen
as a low-risk, low-cost validation tape-out via Skywater 130nm Open MPW.
The product class is `POPC_16A`: the smallest practical PopSolutions Sail.
A locked spec is the prerequisite for top-level RTL integration, PCB
design, and FPGA prototyping.

User mandate: shortest possible path to a tangible, demoable prototype.
This ADR optimizes for speed-to-prototype over feature breadth. Items
deferred here can land in a Generation B silicon refresh
(`POPC_16B` / `InnerJib7ED` or similar) once Gen A is validated.

## Decision

### Compute

- **1 Compute Unit** (`cu_count = 1`)
- **4 SIMD lanes** (`simd_lanes = 4`) — one full-width 256-bit beat = 8 BF16
  values per beat, but matrix-extension lane width is the architectural
  unit. Generation A picks 4 to match the small CU budget.
- **No dedicated NPU.** All INT8 / INT4 inference goes through RVV +
  `Xpop_matmul` custom matrix extension. A dedicated INT8 NPU block adds
  area and verification surface that we cannot afford for first silicon.
- **RISC-V profile:** RVA23 baseline + RVV 1.0 + custom `Xpop_matmul`.
  RV32 (`xlen = 32`); RV64 deferred to a later ADR after Gen A is
  validated.
- **Float support:** BF16 (matrix accumulator FP32) only. No FP64, no
  Tensor Float, no FP8 in Gen A.

### Memory

- **DRAM:** 16 GB DDR5-4800 **SO-DIMM**, single channel, ECC on-die
  (DDR5 standard).
- **AXI4 internal bus:** `mem_data_width = 256` (one cache line per beat),
  `phys_addr_width = 48` per `MAST/src/const.sv`.
- **Scratchpad SRAM:** 256 KB on-die, mapped at fixed address for
  hot-path tensor staging.
- **No HBM** (HBM is reserved for the POPH line).

### Host interface

- **PCIe Gen4 x4** via LitePCIe shim. Gen5 is overkill for POPC class and
  raises packaging cost; Gen4 x4 (~8 GB/s) is plenty for 16 GB DDR5
  weight loads and inference output streaming.
- **No NVLink-equivalent.** No inter-card link in Gen A; multi-card
  scenarios fall back to PCIe peer-to-peer.

### Form factor

- **M.2 22110 NGFF accelerator card** with the DDR5 SO-DIMM mounted
  perpendicular on a daughterboard.
- Rationale: M.2 is the simplest host integration (any modern desktop /
  workstation has an M.2 slot), avoids the BOM cost of an SBC variant
  (CPU, RAM, storage on the card), and matches the cooperative target
  customer (researcher / developer plugging into existing hardware).
- A Mini-ITX SBC variant is **deferred** to a follow-up Sail in the
  same generation if there is demand.

### Power and thermal

- **TDP ≤ 25 W.** Passive heatsink target; small fan acceptable.
- **3.3 V** primary rail from M.2 connector; on-card buck for 1.8 V (DDR5
  controller logic) and 1.1 V (compute core).

### Reference workload

- **TinyLlama-1.1B int4 (Q4_K_M GGML quantization)** at minimum.
- Tracked as benchmark commitment in `popsolutions/InnerJib7EA#3`.

### BOM target

- **R$ 800–1500** for the bare card (excluding DDR5 SO-DIMM, which the
  end user supplies).
- A 16 GB DDR5 SO-DIMM at retail (~R$ 250) puts the total in user hand
  at R$ 1050–1750. Below the price floor of any commercial inference
  accelerator that ships outside Brazil.

### Process target (silicon)

- **Skywater 130nm** via Google Open MPW shuttle.
- **Monolithic die** (no chiplet for InnerJib7EA per ADR-008 in MAST).
- Target die area: ≤ 10 mm² (Open MPW shuttle constraint, with margin).
- Target clock: 100 MHz initially; up to 200 MHz pending timing closure.

## Prototype path

The fastest tangible artifact is **not** silicon — it is an FPGA
bitstream running the full design.

| Milestone | Timeline | Artifact |
|---|---|---|
| RTL end-to-end in Verilator simulation | 2–4 weeks | Cocotb test passes a real workload (sum-integers minimal, then a small ML kernel) |
| FPGA prototype on cheap dev board (e.g. ULX3S, Arty A7) | 4–8 weeks | Bitstream that runs the same workload on real hardware |
| Open MPW shuttle submission (Skywater 130nm) | 6–12 months | Tape-out submitted; ~6 months wafer-to-die after that |
| First silicon validation | 12–18 months total | Working chip on bench |

The FPGA prototype is the credibility-building demo. Tape-out is the
product. Both feed off the same RTL — that is the entire point of the
disciplined Verilator+cocotb harness in MAST.

## Consequences

- **Locks vendor choices** that downstream PRs assume (DDR5 single
  channel, PCIe Gen4 x4, M.2 form factor).
- **Defers capability** — no NPU, no multi-CU, no HBM, no FP64. These
  are explicit non-goals for Gen A. A follow-up ADR can revisit any of
  them for Generation B.
- **Drives FPGA target board choice** to one with at least: ECP5-85F
  or Artix-7 100T equivalent capacity, DDR3/DDR4 SO-DIMM compatible
  (DDR5 unlikely on cheap boards — adapter logic between LiteDRAM-DDR4
  on FPGA and the same logical AXI4 interface as DDR5 on silicon),
  PCIe x4 Gen4 (or simulate via UART for first bring-up).
- **Forces a strict "always test" policy** — every RTL change touched
  by this spec must land with a cocotb testbench, per session feedback
  memory.
